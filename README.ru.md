# PUBG Clan Inviter
[English](README.md) · **Русский**

Программа для Windows, которая сама набирает людей в клан PUBG. Установил, вписал API ключ и ники, дальше две кнопки.

- **Сбор ников: Старт / Стоп.** Программа следит за матчами игроков, которых вы укажете (себя, друзей). Всех реальных игроков из этих матчей она сразу проверяет через официальный PUBG API: в список попадают только те, у кого нет клана. Ники, которые API больше не находит, удаляются. Игроки, которых не видели в матчах N дней (по умолчанию 30), считаются протухшими и тоже удаляются.
- **Приглашения: Начать.** Программа запускает PUBG, сама доходит до страницы «Клан → Приглашения», приглашает нужное число игроков (свежие первыми) и закрывает игру.
- **Чистка клана.** Программа открывает «Активность участников клана», читает таблицу и исключает участников, которые подходят под ваши критерии. Ники из списка исключений не трогаются никогда.

Кнопки и поля игры программа находит по их иконкам на экране, поэтому она работает при любом разрешении, мониторе и языке игры. Ничего записывать и настраивать не нужно. Программа живёт в трее у часов.

## Установка

1. Скачайте `PUBG_Inviter_Setup_x.y.z.exe` со страницы [Releases](../../releases) и запустите. Права администратора не нужны.
2. Получите бесплатный API ключ на [developer.pubg.com](https://developer.pubg.com/).
3. В программе откройте ⚙ настройки. Вставьте ключ и ники, с чьих матчей собирать, и сохраните.
4. Нажмите **Старт** в блоке «Сбор ников». Когда наберётся список, нажмите **Начать** в блоке «Приглашения».

Во время приглашений не переключайтесь из игры: пока окно игры не активно, программа ждёт. **F12** останавливает приглашения.

## Требования

- Windows 10 или 11.
- Язык игры: любой. Кнопки и поля программа находит по иконкам, а не по тексту (проверено на русском, английском и турецком клиентах).

## Как работают приглашения

- Каждый ник используется **один раз**. Программа ищет его в игре и, если игрок нашёлся, один раз нажимает «пригласить». Если не нашёлся, тоже помечает ник как использованный.
- Использованные ники больше никогда не попадают в приглашения, даже если игрок снова встретится в матчах.
- Ответ игры («приглашён», «уже отправлено» и т. п.) программа не читает: так она одинаково работает на любом языке.
- Если лобби загрузилось не полностью, программа сама перезапускает его через меню. При ошибке сервера нажимает «Переподключиться».

## Как работает чистка клана

- Критерии (⚙ Настройки → «Чистка клана»): **еженедельный опыт клана** меньше заданного, **не заходил N дней** (по колонке «Сетевой статус» таблицы; пока только для русского клиента игры) и статус **«Не в сети»** (давно не заходил). Можно исключать при выполнении любого критерия или только всех сразу.
- Таблица читается по положению колонок, а не по заголовкам, а статус «в сети» определяется по цвету. Поэтому опыт, «онлайн» и сами исключения работают на любом языке игры; дни «не заходил» и «Не в сети» пока читаются только на русском.
- Роли программа не читает. Руководителей впишите в «Не исключать никогда» (лидера игра исключить и так не даст). Новичков программа не трогает N дней (по умолчанию 7).
- Кнопка **«Участники»** открывает статистику по каждому участнику за все проверки: опыт за эту и прошлую неделю, средний, вклад, статус, с какого дня в клане, кого и за что исключили.
- Участник исключается через своё меню: программа нажимает последний пункт («Исключить»), проверяет, что в окне подтверждения тот самый ник, и подтверждает пробелом. Потом проверяет, что ник пропал из списка.
- **Пробный режим** включён по умолчанию: программа только пишет в журнал, кого бы исключила. Выключите его, когда список вас устроит.

## Язык программы

По умолчанию программа говорит на языке Windows, в настройках его можно сменить. Сейчас есть русский и английский.

Добавить язык просто: скопируйте `ui/lang/en.json` в `ui/lang/<код языка>.json` (например, `de.json`), переведите строки справа от двоеточия и впишите название языка в `_name`. Программа сама покажет новый язык в списке. Переводы можно присылать через pull request.

Настройки и база лежат в `%APPDATA%\PUBG_Inviter` (`config.json`, `data.db`, `log.txt`).

## Про античит

Программа не читает и не меняет память игры и не трогает её файлы. Она делает только скриншоты экрана и нажимает мышь и клавиатуру через стандартный механизм Windows (`SendInput`), как обычные кликеры. Автоматизация ввода всё равно может нарушать правила игры. Используйте на свой риск.

## Сборка из исходников

Нужны Python 3.13 и [Inno Setup 6](https://jrsoftware.org/isdl.php).

```bat
build.bat
```

Результат: `dist\PUBG_Inviter_Setup_<версия>.exe`. Версия задаётся в `app.py` (`APP_VERSION`). При публикации тега `v*` GitHub Actions сами соберут установщик и приложат его к релизу.

| Файл | Что внутри |
|---|---|
| `app.py` | окна, трей, запуск приглашений |
| `game.py` | поиск элементов игры по тексту и приглашение |
| `ocr.py` | снимок экрана и распознавание текста Windows |
| `collector.py` | PUBG API, база SQLite, сбор и проверка кланов |
| `winput.py` | ввод мыши и клавиатуры |
| `ui/` | интерфейс (HTML/CSS) |
